### 4.2 Why It Changed

The `Package.resolved` file was **newly created** in commit `6658a60` (`chore: checkpoint all Urena changes`). Before that commit, this file did not exist in the repository.

The upgrade from `app-check` 12.0.0 to 12.1.0 was made by the developer (Muhamad Andriyan) during the checkpoint process, likely triggered by:
1. `flutter pub get` resolving a newer compatible version of `firebase_core` / `firebase_messaging`
2. Xcode / Swift Package Manager updating the resolved lockfile to the latest compatible version

This is **automatic dependency resolution behavior** — when SPM resolves Firebase packages, it may pull newer patch/minor versions that are compatible with the SDK.
